# Download speed

Скрипт делает 10 последовательных загрузок по HTTP(S). Для каждой дожидается полного ответа, затем выводит среднее время запроса, общий объём данных и скорость скачивания.

## Запуск

Python 3.10 или новее. Внешние зависимости не нужны.

```bash
python3 speed.py "https://example.com/large-image.jpg"
```

Замените URL на прямую ссылку на существующий файл. Запускайте команду из папки проекта. В Windows используйте `py` вместо `python3`.

Тайм-аут сетевых операций по умолчанию — 30 секунд. Его можно изменить:

```bash
python3 speed.py "https://example.com/large-image.jpg" --timeout 60
```

Это тайм-аут отдельных операций с сокетом, а не ограничение общей длительности загрузки.

## Расчёт

Время измеряется через `time.perf_counter()` от начала запроса до полного чтения и закрытия ответа. Данные читаются блоками по 64 KiB и считаются по фактически полученным байтам тела ответа.

```text
Среднее время = сумма времени запросов / 10
Скорость = общий объём в байтах / сумма времени запросов / 1 048 576
```

Единицы: время — секунды, объём — байты, скорость — **MiB/s**. Один MiB равен **1 048 576 байт**.

Измерение включает подключение и ожидание сервера. Служебные сетевые данные в объём не входят. Скорость зависит от выбранного сервера, размера файла и сети. Перенаправления обрабатываются автоматически: их время учитывается, объём считается по конечному ответу.

При сетевой ошибке, HTTP-ошибке или обрыве ответа с известным размером скрипт завершается с кодом `1`. Итог выводится после 10 успешных загрузок. Ошибка аргументов возвращает `2`, Ctrl+C — `130`.

## Тесты

```bash
python3 -m unittest -v
```

Тесты запускают локальный HTTP-сервер. Проверяются порядок запросов, полное чтение ответов, расчёты, перенаправления, ответы без Content-Length и chunked, ошибки и тайм-ауты.
